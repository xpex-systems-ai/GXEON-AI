# GXEON Voice Operations Agent

Hackathon project for the AssemblyAI Voice Agent Hackathon 2026.

## Mission

Turn spoken operator instructions into structured missions, route them through approved GXEON tools, and return concise evidence-backed results.

## Core Flow

1. Voice input
2. AssemblyAI realtime transcription
3. Intent + mission parser
4. GXEON policy/safety gate
5. Tool execution
6. Evidence collector
7. Voice/text response

## Hackathon Fit

- Voice-first interaction
- Uses AssemblyAI realtime speech-to-text / voice infrastructure
- Demonstrates real-world operational value
- Builds on the existing GXEON agent ecosystem
