## Prioridade e alcance

A classificação não usa apenas dev=true: o dashboard declara bibliotecas de runtime como devDependencies e o build da API gera transport de pino-pretty. logger.ts habilita pretty fora de NODE_ENV=production. Riscos do build podem ser explorados por inputs/servidores de dev mesmo sem caminho no endpoint de auditoria.

Remanescentes GX-01: esbuild 0.27.3 (baixo, corrigido em linha 0.28.1; mudança 0.x exige revisão) e postcss-selector-parser 6.0.10 (moderado, versão corrigida 7.1.6 implica major; revisar compatibilidade Tailwind). Não expor Vite/Metro/tsx publicamente. Proposta: responsável técnico designado pelo proprietário até 2026-10-22.

Remanescentes codegen OpenAPI (markdown-it, linkify-it, js-yaml, fast-uri) e mobile (Expo/Metro, ws 6/7, undici, XML, imagens, certificados, glob/parsers) não são aprovados nem tratados como irrelevantes. Suas atualizações precisam de regressão específica de geração/Expo; esta fase priorizou build/frontend e tooling API. O codegen clean=true não foi executado, pois sobrescreve fontes geradas. Mobile Windows não pôde ser homologado; a proposta é correção separada, validação com fixtures e ambiente isolado, sem consumir entradas externas. Pacotes sem patched_versions exigem mitigação/acompanhar upstream ou substituição revisada, nunca aceite tácito.
