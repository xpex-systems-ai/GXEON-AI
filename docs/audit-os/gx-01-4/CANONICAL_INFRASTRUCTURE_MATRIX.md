Nenhum é oficialmente designado ou homologado ponta a ponta. gxeo e gxeon-ai-a são somente candidatos de backend por raiz; não há API canônica externa comprovada.

Os serviços Railway apontam a xpex-systems-command ou XPeX-Plugin-Factory-, não GXEON-AI. Nenhum foi executado, conectado ou alterado. Em ambos os projetos o ambiente se chama production, inclusive no projeto com staging no nome. O PostgreSQL existente pertence a outro fluxo e não teve credenciais ou dados lidos.

As variáveis estão somente pelos nomes no JSON. Exemplo relevante: gxeon-audit-os tem VITE_GXEON_API_BASE_URL e SUPABASE_SERVICE_ROLE_KE (nome observado, possivelmente incompleto), além de nomes públicos Supabase; o valor/funcionamento não foi inferido. Nenhum valor foi solicitado ou corrigido. Cinco projetos junior-senas continuam 403; nomes/IDs na listagem não concedem acesso aos detalhes. Netlify tem sete contextos e identidade de conta/siteId/configuração não comprovada.

Branches: branch da PR e base main confirmadas. A primeira página de 100 branches não é inventário exaustivo. Domínio listado é configuração do projeto, não prova de alias promovido, DNS saudável ou autorização de publicação.
