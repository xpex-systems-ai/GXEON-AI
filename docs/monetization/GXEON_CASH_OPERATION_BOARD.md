# GXEON Cash Operation Board

The cash operation board is available at `/ops/monetization` and focuses on manual first-revenue execution without external integrations.

## Counters

All counters start at zero:

- Leads: 0
- Propostas: 0
- Clientes: 0
- Receita: R$ 0

## First offers

- Landing Page
- Dashboard
- Portal do Cliente
- CRM Simples

## First monetization workflow

1. Captar lead manually from allowed channels.
2. Validate pain and consent.
3. Register the opportunity in P0.
4. Create the task in P1.
5. Execute the delivery in P2.
6. Validate evidence in P3.
7. Prepare release in P4.
8. Register a real confirmed receipt in P5 only after external confirmation.

## Boundaries

The board does not create fake clients, fake revenue, gateway charges, database writes, invoices, or external API activity.
