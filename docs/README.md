## Convenções

- Português é a língua primária; product terms em inglês são mantidos quando fazem parte da identidade.
- Status de conectores deve permanecer honesto: `CONNECTED_READONLY`, `PARTIAL_READONLY` ou `P0_READY_PENDING_ENV`.
- Diagramas devem ser Mermaid ou markdown-safe.
- Documentos não devem conter segredos, tokens, URLs privadas ou evidências sensíveis.
