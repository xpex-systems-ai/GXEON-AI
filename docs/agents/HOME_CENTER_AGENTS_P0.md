# Home Center Agents P0

Home Center Agents P0 prepares the operational home where future GXEON agents can be installed by Grok Builder after explicit operator approval. P0 is a registry, capability map, permission model and readiness dashboard only.

## P0 boundary

- No autonomous agents are created.
- No agent executes tasks.
- No external users are contacted.
- No emails, DMs, proposals or invoices are sent.
- No GitHub write, repository modification or deployment action is exposed.
- No checkout, capture, refund or money movement is exposed.
- No credential form or frontend secret storage is introduced.

## Opportunity Inbox transition

Radar X can continue to feed manual preview candidates into Opportunity Inbox. The Home Center Agents layer sits beside that P0 pipeline and prepares future agent-assisted planning: Scout reads Radar X candidates, Analyst reads Opportunity Inbox, Proposal/Task/Evidence agents prepare draft-only previews, Revenue tracks readiness and Security/Operator Copilot keep approvals visible.

Nothing in P0 changes Opportunity Inbox behavior. The transition is from manually operated previews to a governed, future-ready agent registry that still requires operator approval before installation or execution.
