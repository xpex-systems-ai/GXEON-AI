# Home Center Agents Preparation

## Current phase

GXEON remains in manual-first P0. The system prepares internal plans that a human operator can inspect, qualify and approve. It does not run autonomous agents, contact prospects or execute revenue actions.

## Why agents are not enabled yet

Home Center Agents need a safe source of scoped opportunities, proposal drafts, task checklists and evidence requirements before any autonomous workflow can be considered. The new Opportunity Inbox provides that substrate while preserving explicit operator control.

## Future Grok Builder phase

After the manual pipeline is validated, future agents can be designed around the existing records:

- Scout Agent for candidate discovery suggestions.
- Analyst Agent for qualification summaries.
- Proposal Agent for draft-only proposal assistance.
- Task Agent for execution planning.
- Evidence Agent for evidence checklist management.
- Revenue Agent for payment readiness after providers are connected.
- Security Agent for boundary enforcement.
- Operator Copilot Agent for human-in-the-loop review.

Each future agent must inherit P0 boundaries until a separate approval phase enables additional capabilities.
