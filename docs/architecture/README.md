# GXEON Architecture Notes

This folder collects architecture notes that support the README module map without duplicating status claims.

## Active repository components

- Dashboard package: `artifacts/gxeon-dashboard/`
- API server package: `artifacts/api-server/`
- Shared contracts: `lib/api-spec/`, `lib/api-zod/`, `lib/api-client-react/`
- Database readiness library: `lib/db/`
- Runtime boundaries: `runtime/`, `events/`, `queues/`, `operators/`, `telemetry/`, `analytics/`

## Future activation components

External APIs, Supabase production activation, payment workflows, and partner integrations remain future/controlled activation work unless a later production-readiness document explicitly updates that status.
