# GitHub Connector Readiness

## Scope

GitHub preparation covers repository metadata, issues, pull requests, commits, and engineering evidence for GXEON execution proof.

## Checklist

- Identify approved repositories and branches.
- Start read-only first wherever possible.
- Define which issue fields are safe to read.
- Define which pull request metadata is needed.
- Define which commit metadata is needed for evidence.
- Confirm no write actions are enabled during initial activation.
- Confirm credentials stay in provider dashboard or secure backend storage.

## Exclusions

No tokens, personal access tokens, app secrets, webhook secrets, or credentials are documented here.
