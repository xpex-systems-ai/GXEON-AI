# Payment, Marketplace, and Wallet Connector Boundary

Mercado Pago P0 supports manual payment-link/Pix guidance and OAuth readiness only. It does not create charges, checkout sessions, captures, withdrawals, or automatic provider verification.

Mercado Livre P0 supports seller setup readiness and planning only. It does not create or update listings, buy products, sell products, message buyers, or post affiliate content automatically.

MetaMask P0 is manual read-only wallet-address readiness with a safety checklist. WalletConnect is planned/not connected in P0. GXEON never asks for seed phrases, recovery phrases, private keys, signatures, transactions, claims, or wallet approvals in P0.
