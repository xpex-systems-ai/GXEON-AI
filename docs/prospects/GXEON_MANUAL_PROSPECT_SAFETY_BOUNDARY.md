# Manual Prospect Safety Boundary

Manual Prospect Pipeline P0 does not scrape leads, harvest contacts, enrich contact data, validate private emails or phone numbers, send WhatsApp/email/Telegram/GitHub messages, create GitHub issues/comments/PRs, create invoices/checkouts, call Mercado Pago/Stripe/Twilio/Gmail APIs, store secrets, or persist CRM data.

All prospect records are operator-provided and in-memory only. Generated messages are copy-only drafts. The operator must perform any external contact or payment verification outside GXEON. Ledger preview is not real revenue: provider verification is false and real revenue claimed is false.
