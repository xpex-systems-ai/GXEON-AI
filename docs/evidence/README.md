# GXEON Evidence Notes

This folder is for curated demo evidence, screenshots, recordings, and review artifacts.

## Evidence rules

- Use `.github/ISSUE_TEMPLATE/visual-evidence.md` for screenshot or Awesome Screenshot submissions.
- Label demo/sample data clearly.
- Do not include secrets, private URLs, credentials, or production environment values.
- Do not use evidence files to claim live external APIs, production database activation, active users, customers, or revenue unless separately validated.
