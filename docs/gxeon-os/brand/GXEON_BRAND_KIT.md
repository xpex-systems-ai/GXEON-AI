# GXEON OS Brand Kit

## Official Name

**GXEON OS**

## Positioning

GXEON OS is a safety-first operating system for AI-assisted digital execution, audits, agents, evidence, proposals and proof-based monetization.

## Taglines

* Primary: Conversa vira comando. Comando vira código. Código vira sistema. Sistema vira produto. Produto vira receita com prova.
* Short: Execution intelligence for AI-powered digital operations.
* PT-BR: Sistema operacional de execução inteligente, agentes e monetização assistida.

## Mission Statement

Capturar sinais, organizar oportunidades, executar com segurança, validar com evidência, monetizar com prova e escalar com agentes.

## Brand Voice

Executive, technological, confident, honest, visionary, operational and free from empty hype.

## Visual System

| Token | Hex | Use |
| --- | --- | --- |
| Deep Navy | `#06111f` | Backgrounds and command center surfaces |
| Black Core | `#030712` | Premium dark base |
| Electric Cyan | `#22d3ee` | Primary highlights and system lines |
| Neon Green | `#7CFF6B` | Execution, safety and success accents |
| Soft White | `#F8FAFC` | Text |
| Gold Accent | `#F6C453` | Monetization and proof markers |

## Visual Direction

Dark premium command center. AI operations, mission control, cybernetic but trustworthy. Use clean grids, terminal-inspired cards, glowing network lines and proof markers.

## Correct Uses

* Use GXEON OS as the official name.
* Use GXEON Audit OS as the active current product line.
* Label future modules as planned or future.
* Label labs as labs.
* Treat monetization as proof-required.

## Prohibited Uses

* Do not claim confirmed revenue without proof.
* Do not claim customers, investors or traction without evidence.
* Do not present GXEON as a fintech, payment processor or unrestricted scraper.
* Do not claim fully autonomous production execution.
* Do not use third-party logos or imply official partnerships without permission.
* Do not expose secrets, private URLs, database URLs, service role keys or tokens.
