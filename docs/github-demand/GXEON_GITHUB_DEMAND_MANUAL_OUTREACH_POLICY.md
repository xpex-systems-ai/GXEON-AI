# GitHub Demand Manual Outreach Policy

GXEON may prepare message drafts for the operator, but it never sends them. Operators must manually verify the issue, maintainer intent, repository rules, allowed channel, bounty terms and acceptance criteria before sending any copy. Drafts are labeled `COPY_ONLY` and `DO_NOT_AUTO_SEND`.

No spam, mass comments, auto PRs, hidden payment assumptions or guaranteed revenue claims are allowed.
