# GitHub Demand Conversion Safety Boundary

The conversion layer is copy-only and manual-send-only. It must not comment on GitHub, create pull requests, contact maintainers, send email or WhatsApp, create payment links, call payment providers, claim a bounty, mark revenue received, execute repository code, clone arbitrary repositories, add workers, add schedulers or persist leads to a database.

Required flags are `PREVIEW_ONLY`, `copyOnly`, `doNotAutoSend`, `manualSendOnly`, `manualReviewRequired`, `githubWriteDisabled`, `externalContactDisabled`, `paymentProviderDisabled`, and `rewardNotGuaranteed`.
