# GitHub Demand Safety Boundary

The module is `PREVIEW_ONLY`. Runtime app code does not comment on GitHub, open pull requests, contact maintainers, spam repositories, scrape GitHub HTML, execute candidate repository code, clone arbitrary repositories, create payments, connect wallets, or persist leads to a database.

Every candidate carries `manualReviewRequired`, `externalContactDisabled`, `githubWriteDisabled`, `rewardNotGuaranteed`, `noAutoPr`, and `noAutoComment` flags.
