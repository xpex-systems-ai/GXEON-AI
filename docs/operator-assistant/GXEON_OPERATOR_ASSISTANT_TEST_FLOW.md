# Test Flow — Operator Assistant P1

1. Abrir `/ops/operator-assistant`.
2. Clicar em **Calcular próxima ação**.
3. Confirmar que a resposta recomenda uma rota interna.
4. Gerar prévia da ação e validar texto copy-only.
5. Criar handoff interno e confirmar que apenas memória da sessão foi atualizada.
6. Verificar que nenhum endpoint de envio, cobrança, GitHub write ou wallet existe.
