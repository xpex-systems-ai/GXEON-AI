## Manual-first and safety boundaries

- Data is static and labeled sample/manual-first.
- The page displays `Manual-first revenue validation` and `No external API calls` badges.
- Active pipeline value is estimated in BRL and labeled as sample-only.
- `WON` status is represented only as a UI state validation sample; it is not real revenue.
- No Supabase, Mercado Pago, LinkedIn, Workana, Upwork, Freelancer, GitHub Projects, Microsoft 365, external API, scraping, database, migration, payment, or automation activation was added.

## Pipeline model

Rendered statuses:

- `NEW`
- `REVIEWING`
- `QUALIFIED`
- `PROPOSAL_READY`
- `CONTACTED`
- `WON`
- `LOST`
- `ARCHIVED`

Active pipeline value counts only `NEW`, `REVIEWING`, `QUALIFIED`, `PROPOSAL_READY`, and `CONTACTED`.
