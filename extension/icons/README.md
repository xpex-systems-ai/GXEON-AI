# 🎨 Ícones GXEON PREDATOR

## Formato necessário

Crie os ícones nos seguintes tamanhos:

- `icon16.png` — 16x16 (para favicon/aba)
- `icon32.png` — 32x32 (para barra de ferramentas)
- `icon48.png` — 48x48 (para gerenciador de extensões)
- `icon128.png` — 128x128 (para Chrome Web Store e notificações)

## Design sugerido

### Cores
- **Primário:** `#D4AF37` (Gold)
- **Secundário:** `#00FFFF` (Cyan)
- **Fundo:** `#0a0e27` (Azul escuro)

### Conceito
Um leão estilizado (predator) com elementos tecnológicos/cyberpunk
ou a letra "G" com um olho (representando vigilância 24/7).

## Ferramentas para criar

1. **Figma** (gratuito) — figma.com
2. **Canva** — canva.com
3. **GIMP** (gratuito) — gimp.org
4. **Photoshop**

## Gerar placeholder temporário

Se não tiver os ícones prontos, use este comando para gerar placeholders:

```bash
# Linux/Mac com ImageMagick
convert -size 128x128 xc:#D4AF37 -pointsize 20 -fill #0a0e27 -gravity center -annotate +0+0 "GX" icon128.png
```

Ou use sites como:
- https://www.favicon.io/
- https://placehold.co/

## ⚠️ Importante

Sem os ícones, a extensão **não carregará** no Brave. 
Certifique-se de ter pelo menos `icon128.png` na pasta `icons/`.
