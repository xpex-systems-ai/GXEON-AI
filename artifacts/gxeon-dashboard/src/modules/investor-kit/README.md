# GXEON Dashboard Investor Kit Module

Future UI placeholder for an investor-readable dashboard surface.

## Planned Cards

* Thesis card.
* Current proof card.
* Roadmap card.
* Honest metrics card.
* Brand and media kit links.
* Portfolio links.
* No-secrets and no-fake-claims rules.

## Safety

This module must use public-safe data only. It must not display secrets, private URLs, unverified revenue, fake customers or fake investors.
