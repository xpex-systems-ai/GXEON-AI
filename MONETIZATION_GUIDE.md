## 🎯 Deploy na Vercel (3 Passos)

### Passo 1: Verificar Environment Variables
Acesse: https://vercel.com/xpexesena-1357/gxeon-ai-7jao/settings/environment-variables

Verifique se estão configuradas:
```
NEXT_PUBLIC_SUPABASE_URL=https://sua-url.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sua-chave-anon
NEXT_PUBLIC_API_BASE=https://gxeon-ia-production.up.railway.app
```

### Passo 2: Executar Deploy
```bash
cd C:\Users\P-c\Documents\xzeon-xpex-1\scripts
vercel-deploy.bat
```

Ou manualmente:
```bash
cd C:\Users\P-c\Documents\xzeon-xpex-1\dashboard
npm run build
npx vercel --prod
```
